#   1. Plain term      : one term per line, added as-is

# The loader checks separators in this order:  →   =   :   ,
# ALWAYS USE  →  (U+2192) FOR HINDI.
# Reason: ':' and ',' are checked too, so any Hindi line containing a comma
# would be silently split into a bogus mapping. '→' cannot collide with
# Devanagari text or with the danda (।).
#
# Keys are lowercased before matching. Devanagari has no case, so this is a
# no-op for Hindi keys but still applies to Latin ones.
# Lines starting with '#' and blank lines are ignored.
# ============================================
